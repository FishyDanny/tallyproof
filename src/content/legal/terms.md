## 1. What Tallyproof does

Tallyproof converts text-based PDF bank and credit card statements into CSV and other file formats. The conversion runs in your browser; your files are not uploaded to us. Tallyproof checks each extracted transaction against the running balance printed on the statement, or, where a statement has no running balance, checks that the opening balance plus all transactions equals the closing balance. Rows or statements that do not reconcile are flagged.

Tallyproof does not support scanned (image-only) PDFs.

## 2. You must check the output

Tallyproof reads statements automatically, using layout detection. Statements vary a lot, and automatic extraction can be wrong. The balance check catches many errors, but not all of them. For example, it does not check that dates or descriptions were read correctly, and the whole-statement check (used when there is no running balance) can show that a total is wrong without showing which row caused it.

Before you import, file or rely on any output, you must review it against the original statement, and in particular every row or statement that Tallyproof flags. You are responsible for the records you create from Tallyproof's output.
